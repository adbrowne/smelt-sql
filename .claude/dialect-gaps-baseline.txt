# Dialect-emission gap ratchet baseline
# Updated: 2026-08-24
#
# Format: <metric> <count>
#
# Each metric is the number of `Verdict::Gap` rows in
# `crates/smelt-db/tests/dialect_audit/ledger.rs` for that dialect — a lowering
# smelt owes, with a tracking issue. The bulk trackers are #177 (DuckDB),
# #178 (Spark) and #179 (BigQuery); rows with a cause of their own point at
# #173 (`%` on BigQuery), #174 (LOG / DAYOFWEEK), #175 (FIRST / LAST) and
# #176 (inference returning Unknown).
#
# This is a RATCHET, mirroring `.claude/parser-gaps-baseline.txt`:
#   - The count may only go DOWN as lowerings land.
#   - Raising it requires editing this file with a reviewer-visible
#     justification and a new ledger entry — never a silent skip.
# `gap_count_ratchet` in tests/dialect_audit/main.rs enforces an exact match
# (a decrease is a "stale baseline" failure prompting you to tighten here).
#
# 2026-09-06 (#181, docs/outcomes/20260904-dialect-emission-vocabulary phase 1,
# sign-off: Andrew Browne): `dialect_gaps_postgres` removed. The PostgreSQL
# emission dialect is retired — no backend crate ever existed to verify its
# verdicts, so the metric is removed because the dialect no longer exists,
# not because its gaps were absorbed.
#
# 2026-09-06 (#177, docs/outcomes/20260904-dialect-emission-vocabulary phase 4,
# sign-off: Andrew Browne): dialect_gaps_duckdb 12 -> 6. Closed: PERCENTILE_CONT
# and PERCENTILE_DISC at Window (already Unsupported in the registry, rows were
# redundant), INITCAP/TO_CHAR/QUOTE_IDENT/QUOTE_LITERAL (Emission::Unsupported —
# none exists on DuckDB 1.5.4, measured live), DATE_SUB (Emission::Template,
# DuckDB spells interval subtraction infix). DATE_ADD's existing type_gap
# survives, and DATE_SUB gained a new one: templating DATE_SUB made its type
# leg run for the first time, and both `DATE_ADD`/`DATE_SUB` turned out to have
# no `SqlFunction` enum variant at all, so the registry's now-corrected
# `Timestamp` return type is never reached by `infer_function_type` — a deeper
# registry-wiring gap than the contingency's unquoted-`INTERVAL`-literal guess
# (that literal already infers `Interval` correctly on its own, measured
# directly). Net: 12 - 7 + 1 = 6.
dialect_gaps_duckdb 6
dialect_gaps_spark 27
