# Phase B: higher-order functions, lambdas, pipe, and config vars

When you need to transform or filter a `List<T>` inline, or read a
workspace-level configuration knob inside a model, Phase B gives you the
vocabulary to do it without leaving smelt SQL.

## When to use

- Filter a list down to a subset at compile time: `filter([a, b, c], fn x => x > 0)`
- Derive a new list by applying a per-element transformation: `map([a, b, c], fn x => x * 2)`
- Fold a list into a single expression using a named reducer: `reduce([a, b, c], comma_sep)`
- Chain operations left-to-right without deeply nested calls: `[a, b, c] |> filter(fn x => x > 0) |> map(fn x => x * 2)`
- Pull a compile-time workspace variable into a model: `smelt.config.var('region')`

## Surface (Phase B)

### Lambdas

- `fn param => body` — single-parameter lambda; body must be a scalar expression
- Used as the second argument to `map` and `filter`
- Lambda params are scoped to the lambda body; they don't refer to table columns

### HOFs

- `map(list, fn x => expr)` — applies `expr` to each element; returns `List<T>`
- `filter(list, fn x => pred)` — keeps elements where `pred` is truthy; returns `List<T>`
- `reduce(list, reducer)` — folds the list using a named reducer; returns a scalar

### Reducers (closed registry)

| Name | Input | Identity | Notes |
|------|-------|----------|-------|
| `comma_sep` | `List<Any>` | n/a | SQL comma-separated expression list |
| `and_all` | `List<Boolean>` | `TRUE` | `AND`-chain; safe on empty list |
| `or_any` | `List<Boolean>` | `FALSE` | `OR`-chain; safe on empty list |
| `union_all` | `List<Any>` | none | no identity; **errors on empty list** |
| `intersect_all` | `List<Any>` | none | no identity; **errors on empty list** |
| `plus_chain` | `List<Numeric>` | `0` | addition fold; safe on empty list |
| `concat` | `List<Text>` | `''` | string concatenation; safe on empty list |

### Pipe operator

- `expr |> call(...)` — threads `expr` as the first argument to `call`
- RHS must be a direct function call (`call(...)` form), not an arithmetic expression
- Chains: `a |> f(...) |> g(...)` evaluated left-to-right
- Only valid as a query-level expression, not as a function argument

### Config vars

- `smelt.config.var('key')` — resolves the `vars.key` entry from `smelt.yml` at compile time
- The argument must be a string literal
- The key must exist in the `vars:` block; missing keys are a compile-time error

## Phase B diagnostics

| Code | Trigger |
|------|---------|
| `LambdaInForbiddenPosition` | `fn x => x` used outside of a HOF argument position |
| `LambdaResultTypeMismatch` | lambda body type doesn't match the HOF's expected element type (e.g., `filter` expects `Boolean` body) |
| `HofExpectsLambda` | `map` or `filter` receives a non-lambda second argument |
| `HofExpectsReducer` | `reduce` receives a lambda instead of a named reducer |
| `HofNameShadowed` | `smelt.define map(...)` shadows the built-in HOF `map` |
| `ReducerNameShadowed` | `smelt.define comma_sep(...)` shadows a built-in reducer |
| `PipeRhsNotCall` | RHS of `\|>` is not a function call (e.g., `list \|> 3 + 4`) |
| `PipeInDataPosition` | pipe expression used as a function argument (not a query-level expression) |
| `ReducerInputTypeMismatch` | list element type doesn't match the reducer's expected input (e.g., `and_all` on integers) |
| `ReducerEmptyNoIdentity` | `reduce([], reducer)` where the reducer has no identity element (e.g., `union_all`) |
| `ConfigVarNotFound` | `smelt.config.var('key')` where `key` is absent from `vars:` in `smelt.yml` |
| `ConfigVarNameNotLiteral` | `smelt.config.var(expr)` where the argument is not a string literal |
| `ConfigVarNullCoercion` | `smelt.config.var('key')` where `vars.key` is `null` (Warning) |

## Workflow gotchas

- **Lambda params are not column refs**: `fn x => x` does not look up `x` in the
  `FROM` clause. The lambda param is a fresh binding scoped to the lambda body.
  Don't use column names as lambda params to avoid confusion.
- **Empty-list identity**: reducers without an identity (`union_all`,
  `intersect_all`) emit `ReducerEmptyNoIdentity` when the list is empty `[]`.
  Use `and_all` or `or_any` (which have `TRUE`/`FALSE` identities) for boolean
  aggregation over potentially-empty lists.
- **Pipe RHS must be a call**: `[1, 2, 3] |> filter(fn x => x > 0)` is valid;
  `[1, 2, 3] |> 3 + 4` is not. The RHS of `|>` must be a named function call.
- **Config vars are compile-time only**: `smelt.config.var('region')` inlines the
  value from `smelt.yml` at compilation; it does not produce a SQL parameter or
  runtime binding.
- **LambdaArityNotSupported** (multi-arg lambdas `fn (a, b) => body`) is deferred
  to Phase F. Only single-parameter lambdas are supported in Phase B.
