# docs-site

Documentation site for smelt, built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/).

## Setup

Dependencies are managed via uv with a local `pyproject.toml`.

```bash
cd docs-site
uv sync
```

## Commands

```bash
# Build the site (output to site/)
uv run mkdocs build

# Live preview with hot reload
uv run mkdocs serve
```

## Structure

- `mkdocs.yml` — Site configuration and nav structure
- `docs/` — Markdown source files
- `docs/assets/editor-features/` — GIFs and screenshots used in the editor features page
- `site/` — Build output (gitignored)

## Rebuilding Editor Feature Images

The GIFs and PNGs in `docs/assets/editor-features/` are generated by the Playwright demo pipeline in `docs/demos/`. They are **not** hand-created — they are automated recordings of the smelt LSP running in code-server.

**Prerequisites:** code-server, ffmpeg, Node.js, Playwright browsers (`npx playwright install`), and a built smelt-lsp binary + packaged VSIX.

**To regenerate all images from the repo root:**

```bash
bash docs/demos/run-all.sh --update-snapshots
```

This builds the LSP, packages the extension, starts code-server, runs all Playwright tests (producing GIFs and screenshots in `docs/demos/media/`), and generates markdown docs.

**After regenerating, copy the assets to the docs-site:**

