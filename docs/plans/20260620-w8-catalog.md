## Design decisions (resolved — do not re-litigate)

| Dec | One-line contract (the spec is authoritative) |
|-----|-----------------------------------------------|
| **D-50(i)** | Column `source` is **always present** in JSON output. When lineage cannot be determined it is `{"type": "unknown"}` — never omitted. A consumer can always read `source.type` without a null-check. |
| **D-50(ii)** | `--select`-**excluded** models are absent from `models`, `tag_index`, `execution_order`, and `project.model_count`. Their **names are retained in `upstream`/`downstream` edge arrays** of selected models (full lineage preserved). Markdown renders excluded deps as plain text (no link), since no `models/<name>.md` exists. |
| **D-50(iii)** | `path` is **workspace-relative** (relative to the directory containing `smelt.yml`), never an absolute filesystem path. This makes the catalog diffable across machines and CI checkouts. |

This phase adds a golden/snapshot assertion to lock that invariant and prevent regression, and fixes any gap if found.

**Critical files.** `crates/smelt-cli/src/docs.rs` (struct `CatalogColumn`), `crates/smelt-cli/tests/docs_json_output.rs`.

If P1 finds the code already correct, the tests are the deliverable — no implementation change needed.

**Reviewer checklist.** `CatalogColumn.source` has no `skip_serializing_if`; all five `CatalogColumnSource` variants serialize correctly; snapshot test committed.

### Phase P2: `path` is workspace-relative, not absolute (D-50(iii))

**Goal.** Change `build_catalog()` (`docs.rs` line 273) so `CatalogModel.path` is workspace-relative (relative to the directory containing `smelt.yml`), not an absolute filesystem path. `build_catalog()` receives the `config` (which has a field resolving to the project root) but currently uses `model_file.path.display().to_string()` directly, which yields an absolute path on any absolute `project_dir`.

**Implementation shape.** Pass `project_dir: &Path` (or derive it from existing args) into `build_catalog()`, then compute `model_file.path.strip_prefix(project_dir).unwrap_or(&model_file.path).display().to_string()`. For multi-model virtual paths (those containing `::`), strip the prefix from the real file portion before the `::`, then re-append the virtual suffix. Alternatively, if `address_segments` already encodes a workspace-relative path form, use that to reconstruct the relative path — but the physical file path is cleaner for the catalog's `path` field.

**Critical files.** `crates/smelt-cli/src/docs.rs` (`build_catalog` signature and line 273), `crates/smelt-cli/src/commands/docs.rs` (call site at line 200), `crates/smelt-cli/tests/docs_json_output.rs`.

**Test idea.** In the integration test `emitted_model_carries_origin_in_real_docs_catalog_pipeline` or a new `catalog_path_is_workspace_relative`: assert `!model.path.starts_with('/')` and that the path matches the expected `models/orders.sql` relative form (not an absolute `/tmp/.../models/orders.sql`). Also assert the `origin.generator_file` path (set in `docs.rs` line 258–261) is workspace-relative — that field likely has the same issue.

**Reviewer checklist.** `path` never starts with `/`; generator `origin.generator_file` is also workspace-relative; `strip_prefix` handles the case where paths aren't under `project_dir` gracefully (falls back to display as-is rather than panicking).

**Commit.** `fix(cli): catalog path is workspace-relative, not absolute (D-50-iii)`

### Phase P3: `--select` preserves full edge lineage; excluded deps as plain text (D-50(ii))

**Goal.** Fix the `--select` filtering in `generate()` (`commands/docs.rs` lines 169–188) so that `upstream`/`downstream` edge arrays of selected models retain the names of excluded models (full lineage), while `models`, `tag_index`, `execution_order`, and `model_count` contain only selected models. Additionally, fix the Markdown renderer (`docs_render.rs` lines 166–178) to render excluded dep names as plain text rather than broken `[link](link.md)` anchors.

**Implementation shape (JSON).** Instead of rebuilding the graph from only selected `ModelFile` entries, keep the full `DependencyGraph` for edge resolution. Apply the selection filter only when building the `models` BTreeMap (skip non-selected model names), computing `tag_index` entries (skip non-selected), building `execution_order` (filter to selected), and computing `model_count`. The `upstream` and `downstream` vecs come from `graph.get_upstream(model_name)` / `dependents_map` on the **full** graph, so excluded names naturally appear in those lists.

**Implementation shape (Markdown).** In `render_model_page()` (or `render_index()`), check `catalog.models.contains_key(dep)` for each name in `model.upstream` / `model.downstream`; if present, render as `[dep](dep.md)`; if absent (excluded), render as plain text `dep`.

**Critical files.** `crates/smelt-cli/src/commands/docs.rs` (lines 169–188), `crates/smelt-cli/src/docs.rs` (`build_catalog` — pass the full graph's edge info, or accept a `selected_names: &BTreeSet<String>` parameter), `crates/smelt-cli/src/docs_render.rs` (lines 166–178), `crates/smelt-cli/tests/docs_json_output.rs`, `crates/smelt-cli/tests/docs_markdown_output.rs`.

**Test idea (JSON).** In `docs_json_output.rs`, add `select_filter_retains_edge_names`: build a 3-model chain `a → b → c`, generate the catalog with `--select b`, assert `catalog.models` contains only `b`; assert `catalog.models["b"].upstream` contains `"a"` and `catalog.models["b"].downstream` contains `"c"`; assert `catalog.execution_order` = `["b"]`; assert `catalog.project.model_count` = 1.

**Test idea (Markdown).** In `docs_markdown_output.rs`, add `excluded_dep_rendered_as_plain_text`: use the same 3-model chain, render markdown for `b`, assert the upstream section contains `a` as plain text (not `[a](a.md)`), and assert no `[a]` link anchor.

**Reviewer checklist.** `models`/`tag_index`/`execution_order`/`model_count` filtered to selected; `upstream`/`downstream` carry full names including excluded; Markdown renders excluded deps as plain text; existing `docs_json_output` and `docs_markdown_output` tests still pass.

**Commit.** `fix(cli): --select preserves full edge lineage; excluded deps as plain text (D-50-ii)`
