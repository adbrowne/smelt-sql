Infrastructure exists (`test_property.rs::find_missing_columns`, `run_property_test`) but `commands/test.rs` never calls them — always uses `run_test` directly. The `cases` field has zero effect in practice. Options: (a) wire `run_property_test` dispatch into `commands/test.rs` — detect omitted columns via `find_missing_columns` before compiling; (b) mark property-based testing as deferred/experimental in the spec. *Recommendation*: (a) — infrastructure is complete and tested.

The spec says "Name of the model under test" without specifying the form. Options: (a) accept only file-stem names and document this; (b) support `smelt.<path>` canonical lookup. *Recommendation*: (a) — document the restriction in the spec.
